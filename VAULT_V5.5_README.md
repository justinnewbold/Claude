## 🧬 How Traits Work

### Inheritance Example:
```
Mother: [Genius, Athletic]
Father: [Lucky, Charismatic]

Child has:
- 50% chance to inherit Genius
- 50% chance to inherit Athletic
- 50% chance to inherit Lucky
- 50% chance to inherit Charismatic
- 5% chance for random mutation (Rad Resistant, etc.)

Possible outcome: [Genius, Lucky, Rad Resistant] 🧠🍀☢️
```

### Trait Effects in Combat:
```
Dweller Stats:
Base STR: 5
Athletic Trait: +2 STR
Equipment: +1 STR
TOTAL: 8 STR

Combat Power = (STR + Weapon Damage) × Skills × Traits × Legendary
```

## ⚡ Legendary Item Hunting

### Drop Mechanics:
- Base chance: **0.1%** per successful expedition
- Luck bonus: +0.01% per Luck point
- Best chance: 10 Luck = 0.2% (1 in 500)

### Farming Strategy:
1. Equip high-Luck dwellers (train at Gym)
2. Send on high-difficulty expeditions (better loot)
3. Use Scavenger skill for bonus caps
4. Patience! Legendaries are RARE

### When You Find One:
- Legendary notification in event log
- Item added to legendary inventory
- Achievement unlocked: "Legendary!"
- Special powers activate when equipped
